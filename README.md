# Gestión de resultados de un torneo local de TCG

## Enunciado del ejercicio

Me han contratado como desarrollador de software para crear una aplicación para un torneo local de PokémonTCG. La primera parte del torneo tomara un mes, en donde cada jugador tratara de conseguir la mayor cantidad de puntos para clasificar. La aplicación debe registrar la identificación y el nombre de cada jugador, las partidas jugadas, y los puntos conseguidos durante el mes. 

### Aclaraciones
- Cada jugador puede participar en diferente cantidad de partidas
- Solo se calculan los resultados correspondientes en un único mes
- El cálculo corresponde únicamente el total de puntos obtenidos
- Pare este ejercicio no es obligatoria almacenar los datos de manera permanente
